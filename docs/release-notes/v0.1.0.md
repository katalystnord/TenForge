TenForge 0.1.0, the first release: analyse a tensile test from any
testing machine's export, in a window that says every next step.

- Open a CSV or text export in any common dialect; force and extension
  columns and their units are found by name and shown, and can be changed.
- Enter the specimen (rectangular, round, tube, or S0 directly) and the
  gauge length; choose ISO 6892-1:2019 (metals) or ISO 527-1:2019
  (plastics), or a profile file of your own.
- Results with the curve, the elastic line and each strength on it. Every
  result is given as reported, or with the reason it could not be found.
- Reports as PDF or HTML, with the data file's and the procedure's
  SHA-256 and the build that made them.
- Test records: an open folder format with every file hashed, the
  imported file kept byte for byte, reopened and re-analysed with any
  change named.
- `tf-analyse`, the same analysis from the command line.

**Every result is "aligned with" its standard, not "to" it.** The
procedures' parameters come from public sources and stay unconfirmed
until checked against the purchased standards, and calibration
certificates cannot be recorded until a later release. The program and
the report say so, with each reason.

Validated against NPL's TENSTAND dataset (all 15 files within the
EN 10002-1 Annex A.5 limits) and BAM's S355 tensile tests; see
docs/validation/phase-1.md.

The AppImage is for x86_64 Linux. Download it, `chmod +x`, run; it
carries Qt and VTK with it. It is built on Ubuntu 26.04 and needs a
distribution with a comparable or newer C library; on an older one it
refuses to start rather than misbehave.

Tension only, files only, one test at a time; compression and bending
come in 0.2. The manual is in docs/manual/.
